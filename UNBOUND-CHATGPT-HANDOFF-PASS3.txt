PRECISE OBSTACLE — DO NOT WORK AROUND IT WITH SHIMS

contrib/unbound/iterator/iterator.c contains six calls to
rpz_callback_from_iterator_cname and rpz_callback_from_iterator_module in three
RPZ-only forged-response/CNAME-rewriting blocks (baseline locations near lines
1431, 2848, 3552). Deleting services/rpz.c/.h while leaving these calls breaks
compilation/linking. Keeping dummy callbacks, disabled implementations, or new
feature switches would violate the task. RPZ uses response-IP address trees,
actions and reply rewriting, so that implementation is still required too.

The iterator directory is byte-for-byte unchanged. RPZ and global response-IP
remain supported, including their configuration and documentation. Per-view
response-IP functionality was removed with views. Do not claim all four
requested third-pass subsystems have been removed.

If the user authorizes narrowly deleting the RPZ-only iterator hooks, remove

ordinary CNAME processing, DNSSEC, EDNS, TCP fallback, cache integration,
upstream selection/retries, ACLs, and global local-zone/local-data behavior.
Otherwise preserve those hooks and record the deferred RPZ/response-IP scope.

COMPLETED IMPLEMENTATION

Incoming DNS TLS: removed TLS DNS listener type/dispatch, accepted-connection
TLS setup, listener contexts, service certificate/key fields and reload tracking,
ticket-key loading/rotation, server ALPN callback, server cipher settings,
additional TLS ports, response padding for encrypted DNS listeners, incoming
TLS statistics, configuration directives/parser tokens, manuals and examples.
Shared TLS helpers required by outbound DNS TLS, anchor HTTPS downloads and
remote-control mutual TLS remain. tls-protocols remains for remote control;
tls-upstream, tls-cert-bundle, tls-use-sni and outgoing query padding remain.
Obsolete ticket/cipher/ALPN-only crypto capability probes were removed.

Plaintext UDP/TCP listeners and their PROXYv2 handling remain. The TLS-specific
PROXYv2 read path is gone. Authority-zone probe code now compares the default
outgoing TLS port constant (853) rather than the deleted server-listener setting;
this does not modify iterator code or remove authority functionality.
Ordinary reload continues refreshing outgoing TLS contexts. Fast reload retains
CA-bundle change detection/context swapping and no longer swaps DNS listener
certificate state.

Views: deleted services/view.c and services/view.h, their portable/BSD build
references and header dependencies, view grammar/configuration structures,
ACL/interface view associations, per-view local answers and response-IP sets,
mesh identity/copy bookkeeping, remote view commands, reload locks/tree swaps,
checkconf validation, callbacks, manuals and examples. The view-only local-zone
'noview' type is removed. Global local zones/data, local tags and ACLs remain.
libunbound local-answer callers were updated to the simplified signature.

Deleted files:
  contrib/unbound/services/view.c
  contrib/unbound/services/view.h
Incoming TLS lived in shared files; its code was physically deleted there.
No build options, compatibility fields, alternate version or new algorithms.
No external library removed: OpenSSL is still required by retained functions.
Four utilities and required libunbound remain.
