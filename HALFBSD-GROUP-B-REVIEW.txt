HalfBSD Group B followup review — 2026-10-02
Audited source revision: 0c30595d79ae

Scope and result
The 15 original B groups were investigated concurrently, then reconciled across kernel/userland/build/install interfaces. No cleanup or removal changes were made. This report is the only new repository file.

There are narrowly scoped cleanup candidates in 11 groups. Two groups should be retained as live functionality (B3 and B7). Two require an explicit compatibility decision before retiring their public surfaces (B8 and B9). Most groups must be split: a safe private subset does not make the entire group removable.

“Safe” here means supported-tree consumers and selection/generation paths have been traced, with the stated interfaces and live functionality preserved. It does not certify unimplemented patches: any subsequent cleanup must be built and tested at a level appropriate to its changes. NIC interrupt/resource changes especially need Ethernet attachment/reset/detach validation on FreeBSD and relevant hardware.

Recommended exact boundaries

B1 — RDMA bridges in functioning Ethernet drivers: TARGETED CLEANUP.
Remove private peer registration/lifecycle bridges and the associated unused RDMA-only state, tunables, auxiliary devices and vector reservations in ice, bnxt and qlnx. There are no surviving peer registrants. Do this coherently with module/manifest selections and cleanup/error paths. Preserve Ethernet drivers, queue/interrupt/reset/DCB/SR-IOV behavior, hardware capability decoding and shared firmware APIs. Do not approve blanket deletion of vendor ecore LL2/RDMA files before resolving their shared dependencies.

B2 — ICL_KERNEL_PROXY: TARGETED CLEANUP; KEEP TCP PROXY.
The iscsid -DICL_KERNEL_PROXY selection and static iSER-only proxy send/receive paths target the removed provider and can be retired, preserving explicit unsupported-iSER rejection. Whole icl_soft_proxy.c removal is not safe: icl_listen_add(false) and icl_soft_proxy_connect implement TCP, with optional ctld/CTL builds supporting it. Preserve generic ICL methods and ioctl numbers/layouts. Empty default-build compilation is not proof that an optional implementation is orphaned.

B3 — Generic kernel RPC runtime: KEEP; CORRECT TO INTENTIONAL SURVIVOR.
rpcbind explicitly attempts to load krpc and creates its Netlink transport. Its local Netlink configuration is hardcoded, not read from /etc/netconfig. Failure to load krpc warns and disables that integration, rather than terminating all rpcbind service. libc svc_nl and genl also consume the protocol. Removing the entire runtime would withdraw functioning support; no further private subset is approved by this review.

B4 — WebNFS public-export state: TARGETED CLEANUP WITH ABI PRESERVED.
No protocol consumer of nfs_pub remains. Its state allocation, public-root file-handle creation and teardown are removable. Preserve generic VFS exports/file handles, MNT_EXPUBLIC's numeric reservation and export_args layouts including ex_indexfile. Public-export requests should be explicitly rejected with EOPNOTSUPP. Retain a compatibility vfs_setpublicfs stub if preserving the exported kernel entrypoint. Full removal of exported state/types/interfaces is a separate compatibility question.

B5 — MAC NFS credential hook: TARGETED PRIVATE CLEANUP.
Remove the static Biba/MLS/stub NFS credential-association callbacks and their initializer assignments, which have no remaining in-tree caller. Preserve the mac_policy_ops operation slot/type and exported framework surface (a compatibility stub is an option). MAC_VERSION=6 represents exact module ABI matching; deleting the slot and shifting later callbacks is not safe cleanup.

B6 — ALTQ: TARGETED PRIVATE IPFW CLEANUP.
Remove excluded NO_ALTQ implementation branches, associated private token/scaffolding/always-NULL state and the unsupported help text. Preserve log/tag syntax, legacy O_ALTQ encoding and explicit EOPNOTSUPP rejection. Keep installed if_altq.h, queue structure layout and tbr_dequeue_ptr: the latter has a real definition and queue consumers. Removing installed ALTQ callable declarations requires source-compatibility policy; do not treat the entire header as dangling.

B7 — etcupdate mail hook: KEEP; LIVE CUSTOM/HISTORICAL INPUT SUPPORT.
Base aliases/newaliases producers are gone, but etcupdate accepts alternate source trees and saved tarballs. Those inputs can still reach the aliases post-install hook and staged-root warning. A stubbed execution harness confirmed live-root invocation, staged-root warning, dry-run suppression and unrelated-file isolation. Removing the hook would withdraw supported input behavior, rather than simply clean dead code. A missing-command guard would be a separate possible improvement.

B8 — PF/manual identities: COMPATIBILITY DECISION REQUIRED.
No current base owner/name-lookup consumers were found for man/proxy/authpf/_pflogd. However passwd/group installation and etcupdate merge paths are live: deleting records can affect upgrades as well as new images. This source audit cannot prove the absence of externally installed services or numeric ownership. Decide identity/upgrade policy before deletion; never reuse UID/GID 9/62/63/64.

B9 — Historical Kerberos RPC headers: COMPATIBILITY DECISION REQUIRED.
KRB4 callable declarations have no in-tree implementation or symbol-map exports, and KERBEROS header dependencies/conditional syntax were already broken in the FreeBSD baseline. Installed auth_kerb.h is still a public source surface, including for code that includes it without enabling KERBEROS. Header/declaration retirement needs an explicit policy, or an inert compatibility header. Preserve AUTH_KERB=4, historical error slots and libc's error decoding; normal Secure RPC/GSS behavior is outside this cleanup.

B10 — Unsupported native architecture remnants: SAFE SCOPED REMOVAL.
Remove four libproc native __riscv register-access branches, the unselected libdtrace PowerPC backend, and 64 generated kernel OpenSSL PowerPC/powerpc64/powerpc64le files plus solely native wrapper/header arms. Supported build selectors and current assembly-generation loops exclude those architectures. Preserve supported native backends, public libproc/DTrace/crypto APIs and imported OpenSSL foreign-target generators. Do not equate generated kernel copies with upstream perlasm sources.

B11 — RISC-V old-object repairs: SAFE SCOPED REMOVAL.
Remove the two MACHINE=riscv blocks in tools/build/depend-cleanup.sh. Supported native target lists cannot execute them. Keep generic/supported-target dependency repairs and historical installed-file cleanup inventories. This retires the standalone helper's manually requested cleanup of historical RISC-V object trees, not current build behavior.

B12 — Old examples/docs/package/test: TARGETED CLEANUP, PRESERVE HISTORY.
Remove the unselected release/packages/ucl/rcmds.ucl fragment; no surviving base package producer selects it, and its inclusion is optional package-specific metadata. Correct printf's active legacy locale test to exercise documented C-byte fallback or explicitly skip an unavailable ISO locale; do not delete working printf coverage. The missing locale does not prove a test failure because printf falls back to the unsigned byte. Preserve explicitly historical 4.4BSD setup documentation and crunch examples, optionally labeling obsolete example manifests.

B13 — Manual source/build metadata: TARGETED INERT METADATA ONLY.
The stand/man parent traversal and inert Makefile can be retired without deleting loader source documentation. Preserve installed mdoc examples and standalone deshallify.sh; they remain independently useful. libpcap's named sed conversion targets remain manually callable even though ordinary builds don't install manuals, so retiring those targets is a developer-tooling decision, not proven orphan implementation. Keep vendor/public API documentation and obsolete installed-manual cleanup records.

B14 — OFED-named LinuxKPI constant/diagnostics: KEEP USEFUL SURFACE; TINY METADATA CLEANUP.
Keep generic _module_run diagnostics, MODINIT ordering and the externally visible PREINIT compatibility constant. The OFED name does not prove orphanhood. opt_ofed.h SRCS entries in carp, fwip, cxgbe/if_cxgbe, cxgbe/if_cxgbev and toecore generate unused headers: no source includes them and forced option inclusion uses opt_global.h. Those five unused generation entries are a safe small cleanup. Retiring/renaming the debug option or PREINIT constant is separate compatibility work.

B15 — Stale DIRDEPS: TARGETED HANDWRITTEN CLEANUP; REGENERATE BROADER GRAPHS.
Remove the obsolete GNU_GREP_COMPAT option fragment (current grep already depends on lib/libregex). Replace libproc's retired LIBCPLUSPLUS choice with an unconditional libcxxrt dependency while retaining CDDL selection. The entirely unsupported handwritten GCC/GNU pseudo targets and GNU-only edges in the mixed toolchain pseudo target can be retired, preserving functioning toolchain dependencies. Do not delete the entire toolchain target. For 121 old gnu/lib/csu graph edges, regenerate dependencies on a supported FreeBSD meta/DIRDEPS host with filemon. Resolve .host qualifiers and current startup-object paths; the earlier 404 raw missing-path candidates are not 404 verified orphans.

Checking performed and limits
- Repository-wide producer/caller/registration searches and build/install/generation tracing.
- Supported native-target selection and upstream baseline comparisons.
- Public ABI/layout, numeric reservations, symbol maps and upgrade-input analysis.
- Cross-subsystem reconciliation: rpcbind/krpc, if_altq/ifq, optional ICL TCP proxy, current package template selection, LinuxKPI forced option headers.
- etcupdate behavior harness using the actual extracted post_install_file function and stubbed external commands; no real installation writes.
- No native build, actual FreeBSD module loading, physical-NIC test, ports/installed-system ownership inventory or authoritative DIRDEPS regeneration was available. Recommendations distinguish these limits rather than claiming universal external compatibility.
