HalfBSD AMD64 kernel-module build inventory
==========================================

Source Makefiles evaluated on Linux using BSD make, MACHINE=amd64,
MACHINE_ARCH=amd64 and MACHINE_CPUARCH=amd64. Default HalfBSD module filters
were applied and SUBDIR groups expanded recursively. No modules were compiled.
This is a source-build inventory, not Anvil's installed or loaded module list.
Native build options, firmware selection and MODULES_OVERRIDE/MODULES_EXTRA/
WITHOUT_MODULES can change the result. Firmware generated within an individual
module Makefile may not appear as a separate KMOD entry here.
The .WAIT token under tests is an ordering barrier, not a module directory.
Some entries are also compiled into HALFBSD itself; building a .ko copy does
not mean it needs to be loaded. External AMDGPU/drm-kmod is outside this list.

For the exact installed files on Anvil:
find /boot/kernel /boot/modules -type f -name '*.ko' -print | sort
For currently loaded files: kldstat
