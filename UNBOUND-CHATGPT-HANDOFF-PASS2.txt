WHAT WAS REMOVED

Redis/cachedb: module, Redis backend, query helper, configuration grammar and
fields, module registration, callbacks, cache backend statistics, hiredis
dependency support, and the administration command's +c backend selector.
Ordinary cache flush commands remain. An orphan copied cachedb type in ipset
was corrected to ipset_qstate; a stale commented reference in ipsecmod is gone.

ECS/subnetcache: module, address tree, whitelist, option encoding/parsing,
separate caches, prefetch hooks, statistics, configuration, and ECS formatter.
Unsupported ECS options now follow ordinary EDNS handling: ignored, never
propagated upstream, and no separation of the shared cache. The IANA registry
entry for option 8 remains solely as protocol identification.

DNSCrypt: protocol implementation, certificate/configuration sources,
decrypt/encrypt listener paths, daemon state, cache accounting, statistics,
directives, documentation, and libsodium dependency probes.

DoH server: HTTP/2 sessions, requests, streams, listeners, ALPN context,
buffer accounting, mesh bookkeeping, reload handling, directives, manuals,
and nghttp2 dependency support. Outgoing HTTP/1.1 and HTTPS download clients
remain for unbound-anchor and the retained authority-zone machinery.

DoQ: QUIC sockets, connections, streams, timers, connection tables, protocol
TLS context, listener types, callbacks, configuration, statistics, documentation,
and ngtcp2/crypto-adapter dependency support.

These were physical source removals, including shared-file implementations,
not disabled preprocessor branches or new build options. Lexer/parser sources
and generated outputs, configure sources/generated configure, build references,
headers, registration, examples, and user-facing documentation were cleaned.
Obsolete unitecs/unitdoq/dohclient/doqclient build references were removed;
their test implementations were already absent from this import.
Historical upstream Changelog/CREDITS remain as provenance. dnscrypt.org in
the warmup domain list is an ordinary domain, not a protocol implementation.
